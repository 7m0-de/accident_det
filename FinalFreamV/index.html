Colab GPU Pipeline Setup

Follow these quick steps to execute the accident detection backend on Google Colab:

  1. Open Google Colab and select a T4 GPU hardware accelerator.
  2. Clone the repository and install requirements: 
    !git clone https://github.com/ayman/Accident-Detection.git
%cd Accident-Detection
!pip install -r requirements.txt
  3. Start localtunnel to tunnel the FastAPI port: 
    !npm install -g localtunnel
!python app.py & lt --port 7860
  4. Copy the generated https://xxxx.localtunnel.me URL and paste it into the connection input.
